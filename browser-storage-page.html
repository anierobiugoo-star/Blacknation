localStorage

Permanent Memory

Data stays until you manually delete it. Like writing on a wall with permanent marker — it survives page refreshes, browser restarts, and laptop shutdowns.

sessionStorage

Temporary Memory

Data lives only while the tab is open. The moment the tab closes — everything is gone. Like notes written on your hand that wash off when you shower.

Core API Methods

Every method you need to know

Both localStorage and sessionStorage share the exact same methods. Learn one, you know both.

setItem(key, value)

Save data. Always stores as a string. Think of it as writing a label on a locker and putting something inside.

getItem(key)

Read data. Returns the value or null if not found. Like opening the locker to check what's inside.

removeItem(key)

Delete one specific item. Everything else stays. Like taking only your documents out of the locker.

clear()

Delete everything in storage. Nuclear option. Like emptying the entire locker at once.

JSON.stringify()

Pack an object into a string before saving. You cannot store objects directly — they must be converted first.

JSON.parse()

Unpack a string back into an object after reading. The reverse of stringify — converts text back to usable data.

Storing Complex Data

JSON.stringify & JSON.parse

localStorage only speaks strings. To store objects and arrays, you must pack them first and unpack when reading. This is the most important skill for real projects.

Save a student object to localStorage, then read it back and access individual properties.

let student = {
  name: "Chidi Okeke",
  level: 300,
  cgpa: 4.5
};

// Pack before saving
localStorage.setItem("student", JSON.stringify(student));

// Unpack after reading
let saved = JSON.parse(localStorage.getItem("student"));
console.log(saved.name); // "Chidi Okeke"
Click "Save Student Object" to begin.

Save an array of students, read it back, and loop through it.

let classList = ["Chidi", "Emeka", "Amaka"];

// Stringify before saving
localStorage.setItem("classList", JSON.stringify(classList));

// Parse after reading
let saved = JSON.parse(localStorage.getItem("classList"));
saved.forEach(name => console.log(name));
Click "Save Array" to begin.

Numbers come back as strings. Always convert after reading or your math will break.

localStorage.setItem("score", 85);

// Comes back as string — WRONG
let wrong = localStorage.getItem("score");
console.log(wrong + 10); // "8510" — wrong!

// Convert back — CORRECT
let correct = Number(localStorage.getItem("score"));
console.log(correct + 10); // 95 — correct!
Click a button to see the difference.

Golden Rules

Three things to never forget

Break any of these and your storage code will give you bugs that are very hard to track down.

01

Everything is a string

Numbers, booleans, objects — all become strings when saved. Use Number() for numbers and JSON.parse() for objects when reading back. Forgetting this breaks your math silently.

02

Always check for null

If a key doesn't exist, getItem() returns null. Calling JSON.parse(null) returns null — but accessing null.name crashes. Always check if the value exists before using it.

03

Never store sensitive data

Passwords, BVN, card numbers, PINs — never in localStorage. Anyone with access to the browser can read it. It is plain text with zero encryption. Use it only for preferences and non-sensitive state.
